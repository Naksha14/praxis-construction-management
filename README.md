# Praxis

## Civil Engineering & Construction Project Management

Praxis is a focused web application built to help civil engineers, construction administrators, site teams, and project in-charges manage essential project information in one place.

### Key features

- Construction project creation, tracking, and assignment

- Project in-charge coordination with role-based access

- Revenue, payments, and expense monitoring

- Project document, photo, and video management

- Activity updates for important project changes

- Recycle Bin for safe recovery of deleted records

- Responsive interface for desktop, tablet, and mobile use

### Technology

Praxis is a pure static web application connected directly to Supabase for data persistence, authentication workflow, and file storage.
